# Поддержка / Support

Создайте [GitHub issue](https://github.com/Kay0k1/telegram-dev/issues/new) с названием агента, версией Telegram Dev, шагами воспроизведения и ожидаемым результатом. Для ошибок документации приложите URL официальной страницы и вывод `telegram-dev status`. Удалите токены, личные сообщения и другие секреты.

Это общественный проект: гарантированного времени ответа нет. Работа удалённого MCP относится к поддержке его оператора. Сообщение об ошибке не означает, что плагин принят в официальный каталог.

Open a [GitHub issue](https://github.com/Kay0k1/telegram-dev/issues/new) with your agent, Telegram Dev version, reproduction steps and expected result. For documentation problems, include the official source URL and `telegram-dev status` output. Remove tokens, private messages and other secrets.

This community project has no guaranteed response time. A separate hosted MCP is supported by its operator. An issue report is not a marketplace submission receipt.
