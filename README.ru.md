# Telegram Dev

Открытый скилл и MCP для разработки в Telegram: актуальная документация, выбор нужного API и проверка результата. Отдельно разобраны красные кнопки, premium/custom emoji, стикеры, голосовые, кружки и Mini Apps.

## Установка

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/), затем:

```sh
git clone https://github.com/Kay0k1/telegram-dev.git
cd telegram-dev
uv run --frozen python scripts/install.py --agent codex --project /полный/путь/к/проекту
```

Вместо `codex` можно указать `claude` или `cursor`. На Windows укажите свой путь в кавычках. Установщик подключает сразу MCP и скилл, сохраняет посторонние настройки и создаёт резервную копию существующего файла настроек. Уже установленный Telegram Dev автоматически не перезаписывает.

Оставьте скачанную папку на месте. Откройте новую сессию агента и включите проектный MCP, если приложение это предложит. Для Codex проект должен быть доверенным.

## Через каталог Claude Code

Если `uv` установлен и доступен приложению, выполните в Claude Code:

```text
/plugin marketplace add Kay0k1/telegram-dev
/plugin install telegram-dev@telegram-dev-tools
```

Это собственный каталог проекта на GitHub. Он не означает размещение в официальном каталоге Anthropic. Выберите этот вариант либо установщик выше, чтобы не дублировать подключение.

## Использование

Напишите агенту:

> Используй telegram-dev. Проверь базу, загрузи актуальную страницу Bot API и найди, как сделать красную кнопку с premium emoji. Прочитай требования и покажи ссылки. Ничего не отправляй в Telegram.

После проверки можно давать обычные задания по своему проекту с указанием «используй telegram-dev».

Публичная версия загружает нужные документы по запросу и сохраняет их в локальном кеше. Токен Telegram для этого не нужен. Полный предварительный сбор документации не требуется; готовая база из предыдущего локального прототипа не входит в публичный исходный пакет.

При желании загрузить весь обнаруженный набор источников:

```sh
uv run --frozen telegram-dev sync --max-pages 0
```

## Как поделиться

Отправьте [ссылку на репозиторий](https://github.com/Kay0k1/telegram-dev) или [страницу релизов](https://github.com/Kay0k1/telegram-dev/releases). Разработчик скачивает исходники и запускает установку для своего агента. Сгенерированные настройки содержат пути его машины.

Это экспериментальная версия. Технические проверки инструмента не гарантируют безошибочную работу агента. В официальные магазины Cursor/OpenAI проект пока не отправлен. Подробности, тесты, ограничения и лицензия — в [основном README](README.md).
